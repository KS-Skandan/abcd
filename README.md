# Workplace Safety Sentinel - ABCD Hub

A modern, responsive physical AI operations website demonstrating the **Workplace Safety Sentinel** perception pipeline and zero-masking multi-object safety logic.

## 🚀 Live Demo URL
* **GitHub Pages URL**: `https://<your-username>.github.io/abcd/`

## 🛠️ Technologies Used
* **HTML5**: Semantic UI, canvas viewports, telemetry tables.
* **CSS3**: Dark mode industrial SCADA theme, responsive grid, alert animations.
* **JavaScript (ES6+)**: Real-time spatial point-in-polygon engine, zero-masking logic, Web Audio API tone synthesizer.
* **Java**: `BackendServer.java` standalone standard HTTP server providing REST API endpoints.

## 🏃 Running Locally

### Option 1: Direct in Browser
Open `index.html` in any modern web browser.

### Option 2: Java Backend Server
```bash
javac BackendServer.java
java BackendServer
```
Visit `http://localhost:8080`.

### Option 3: Deploy to GitHub with Live URL
```bash
python deploy_to_github.py --token <YOUR_GITHUB_PERSONAL_ACCESS_TOKEN>
```
